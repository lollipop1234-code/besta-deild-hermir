# Besta deild hermir

Léttur, gagnvirkur hermir fyrir leikjafyrirkomulag Bestu deildar karla.

Markmiðið er einfalt: breyta forsendum, sjá hvernig mótið passar inn í íslenska knattspyrnudagatalið og fá skýrar viðvaranir þegar uppsetning rekst á reglur eða óheppilegt leikjaálag.

Verkefnið er viljandi án gagnagrunns, innskráningar og þungs bakenda. Allt keyrir í vafranum.
